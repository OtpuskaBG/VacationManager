The project

Practical workflows, all in one place.

The current codebase brings together the building blocks for structured people and project administration.

▦

Leave requests

Employees submit time-off requests, with a manager-oriented approval workflow.

♙

Team management

Create and manage teams with developers, team leads, and assigned projects.

▤

Role-based access

Separate actions and visibility for organization roles with authentication and authorization.

Under the hood

Built on a familiar .NET foundation.

A C# application with a server-rendered Blazor interface, ASP.NET Core services and a data access layer.

  • ✓C# and ASP.NET Core application architecture
  • ✓Blazor Server user interface
  • ✓Repository and service patterns for project and team logic
